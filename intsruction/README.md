Трекер настроения и продуктивности
Интеллектуальный Telegram-бот, который помогает пользователю отслеживать ежедневное самочувствие и продуктивность, выявляя скрытые закономерности на основе накопленных данных


О проекте
Проблема: Мы часто не замечаем, как режим сна, количество учебы или работы влияют на наше настроение и эффективность. Субъективные ощущения ненадежны, но цифры — нет.
Решение: Бот ежедневно запрашивает три показателя (настроение 1–5, часы работы/учебы, часы сна), сохраняет их в базу данных и анализирует. Пользователь получает персонализированные инсайты (в какие дни настроение выше, как сон влияет на продуктивность), основанные на реальных цифрах, а не на догадках

Технологии
Python 3
pyTelegramBotAPI (Telebot)
SQLite (структура совместима с PostgreSQL)
Pandas, Matplotlib (для аналитики и графиков)


Структура проекта
bot.py — Основная логика бота, обработчики команд и состояний
db_handler.py — Взаимодействие с базой данных
analyzer.py — Аналитика, генерация инсайтов и построение графиков
config.py — Загрузка токена из переменных окружения
schema.sql — SQL-скрипт создания таблиц и индексов
test_data.sql — SQL-скрипт с тестовыми данными (15 записей)
requirements.txt — Зависимости проекта
.gitignore — Исключения для Git
.env — Файл с токеном (не попадает в GitHub)
README.md — Документация


Установка и запуск
Клонируйте репозиторий и перейдите в его папку:
git clone <https://github.com/Parovv/practic>
cd mood_tracker


Создайте и активируйте виртуальное окружение:
Windows: python -m venv venv, затем venv\Scripts\activate
Mac/Linux: python3 -m venv venv, затем source venv/bin/activate


Установите зависимости:
pip install -r requirements.txt


Создайте файл .env в корне папки и добавьте токен бота:
BOT_TOKEN=ваш_токен


Запустите бота:
python bot.py


Команды бота
/start — Запуск бота, приветствие и инструкция
/add (➕ Записать день) — Пошаговый ввод данных за сегодня (настроение, работа, сон, комментарий)
/stats (📊 Статистика) — Меню аналитики: сводка за неделю/месяц, инсайты, график
/history (📜 История) — Последние 10 записей
/settings (⚙️ Настройки) — Установка времени ежедневного напоминания
/clear (🗑 Очистить данные) — Удаление всех данных с подтверждением
/help — Краткая справка


Схема базы данных
В проекте используется 2 таблицы: users (пользователи и настройки напоминаний) и records (ежедневные записи). Связь: один ко многим (1:N). Ограничение: одна запись в день на пользователя (UNIQUE). Визуальная схема доступна на drawSQL: [https://drawsql.app/teams/gipermtgaithu8b/diagrams/telebot]


Тестовые данные
Для проверки аналитики используйте файл test_data.sql. Он содержит 15 записей за разные дни. Загрузите его в базу данных через любую программу для просмотра SQLite (например, DB Browser for SQLite).
